# Mascotas del recorrido de un pedido

Ocho renders originales generados con la herramienta integrada imagegen el 28 de octubre de 2026. Referencia de identidad: `../sayri-octopus.webp`. Cada etapa tiene una postura y accesorios propios; fondo transparente generado, sin extracción posterior.

- Cliente: saludo y ficha de cliente.
- Pedido: registro en tablet.
- Stock: cajas y escáner.
- Procesamiento: preparación y etiquetado de una caja.
- Facturación: comprobante y calculadora.
- Cobranza: terminal de pago y tarjeta.
- Analítica: lupa y gráficos.
- Decisión: brújula y dirección.

Los PNG originales se conservan en `sources/`; los WebP son las versiones para la web. Prompts y procedencia en `generation.json`. `OrderJourney.tsx` vincula cada imagen a la misma selección que controla el detalle, tanto con tarjetas como con controles y teclado.
