# Emblemas tecnológicos

PostgreSQL, Python, Django, React y Git: SVG monocromos de Simple Icons, descargados desde https://github.com/simple-icons/simple-icons/tree/develop/icons el 28 de octubre de 2026. Licencia de Simple Icons: CC0; las marcas pertenecen a sus titulares. React Native reutiliza el emblema React con marco de celular en CSS. AWS se presenta mediante marca tipográfica y sonrisa SVG; CI/CD usa un ciclo SVG propio, sin atribuirlo a un producto particular.
